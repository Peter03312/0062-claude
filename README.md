# 编带等价论证册（Braid Equivalence Book）

> 十三至十七岁数学艺术社展签工具：当两个编带过程的**末端排列相同**时，逐步核查它们在
> Artin 编带群里是否真的代表同一个元素。纯前端、完全离线（React + Vite + SVG），
> 每一步局部改写都由引擎复现，**绝不**仅凭末端排列判等。

## 这是什么

给定 3～7 股编带，输入两个**起始词**和各自的**线性论证路线**。每一步声明：

1. **前一步**（第 1 步必须是起始词，之后必须是紧邻的上一步）；
2. 父词上的一个**连续片段** `[起, 止)`（生成元下标，从 0 起）；
3. 所使用的**公理**。

允许的公理只有四类（i 为 1 … 股数−1）：

| 公理 | 形式 | 片段 |
|---|---|---|
| 逆元相消 | σi σi⁻¹ = 1，σi⁻¹ σi = 1 | 长度 2 |
| 逆元插入 | 1 = σi σi⁻¹ | 空片段（起=止，表示插入位置），给参数 i |
| 远交换 | σi σj = σj σi，当 \|i−j\| ≥ 2 | 长度 2 |
| 辫关系 | σi σi+1 σi = σi+1 σi σi+1 | 长度 3，仅正生成元 |

引擎在父词上**复现局部改写**，再与你填写的“本步所得词”逐字母核对。
按步序给出**第一个**问题：越界的生成元下标、片段越界、用错的公理、断裂的前序或不符的结果。

### 为什么排列相同还可能不等价

σi 诱导的末端只是一个置换，但编带群 B_n 比置换群 S_n 大得多。本工具按词从左到右计算
**Artin 自由群表示** B_n → Aut(F_n)，F_n 的基写作 x1,…,xn：

- σi 把 `(xi, xi+1)` 变成 `(xi xi+1 xi⁻¹, xi)`；
- σi⁻¹ 把 `(xi, xi+1)` 变成 `(xi+1, xi+1⁻¹ xi xi+1)`；

每次替换后**反复约消相邻逆元**。两条路线都合法时，逐分量比较自由群元组，
首个不同的分量会被明确指出，并展示该分量两边的自由群词。

内置反例 **σ1² 与 σ2²**（3 股）：两者末端排列都是恒等，Artin 像却不同——
第 1 个分量分别是 `x1x2x1x2⁻¹x1⁻¹` 与 `x1`。

> 注意：σ1σ2 与 σ2σ1 **不是**这类反例——它们在 S3 里是方向相反的两个 3-轮换，
> 连末端排列都不同。这一点也有单元测试锁定，防止错误示范混进展签。

## 符号与索引示例

词法（分隔符为空格或逗号，大小写均可）：

- `σ1`、`s1`、`sigma1` 都表示 σ1；
- 逆元：`σ1^-1`、`s1-1`、`σ1inv`、`σ1⁻¹`（Unicode 上标）；
- 纯数字 `1` 也可表示 σ1。

片段索引（关键！）：词 `σ1 σ3 σ3⁻¹` 的生成元下标依次是

```
生成元      σ1   σ3   σ3⁻¹
下标        0    1    2
```

- 相消掉 σ3 σ3⁻¹：片段 `[1,3)`；
- 在开头插入 σ2 σ2⁻¹：空片段 `[0,0)`，参数 i = 2；
- 交换 σ1 σ3：片段 `[0,2)`（4 股时 |1−3|=2，合法）；
- 辫关系 σ1σ2σ1 → σ2σ1σ2：片段 `[0,3)`。

## 页面怎么用

1. 顶栏选股数（3～7）或载入内置示例；
2. 左右两栏分别填起始词，用“添加论证步骤”构建线性链；
3. 点步骤卡片可展开：同步绘制父词编带 SVG，黄底标出选中片段，
   插入公理显示红色插入位置虚线，右侧按列标注 σi / σi⁻¹；
4. “核查结论”实时显示每路合法性、末端排列、自由群元组与等价判定；
5. 两路都合法后可点**封存并生成展签**：生成带内容指纹与时间戳的可打印展签文本；
6. **任何编辑都会自动作废旧结论**（指纹 FNV-1a 不符即清除），页面提示重新封存；
7. 草稿自动离线保存，也可命名备份并一键恢复（localStorage，不联网）。

## 测试

```bash
npm test           # Vitest：引擎单元测试
npm run test:e2e   # Playwright：界面失效测试（自动构建并起预览服务器）
SMOKE_URL=http://127.0.0.1:4173 node scripts/smoke.mjs
                   # 首页冒烟（HTML + 本地资源可达 + 无外部 CDN）
```

覆盖范围：

- **三类公理**：逆元相消/插入、远交换（含相邻下标被拒）、辫关系（正反方向与非法模式）；
- **逆元约简**：相邻逆元反复消尽、a·a⁻¹=1、Artin 像各分量始终约消；
- **同排列非等价反例**：σ1² vs σ2² 的排列相同、元组不同、首个不同分量为 1；
- **错误定位**：首个越界下标（含位置）、片段越界、断裂前序、所写结果与公理不符；
- **界面失效**：结论/横幅渲染、公理选错即时报错、编辑清除旧封存、草稿恢复、SVG 片段高亮。

> Playwright 的 Chromium 需要系统库（libnss3、libgbm1 等）。Debian/Ubuntu 上
> `npx playwright install --with-deps chromium`；无 root 环境可下载对应 .deb
> 解压后以 `LD_LIBRARY_PATH` 提供（Docker verify 镜像基于 node 镜像，库已齐备）。

## Docker Compose

只有一个常驻服务：静态 `web`（nginx，容器内 8080）。

```bash
# 构建并常驻（默认宿主端口 8080）
docker compose up web --build

# APP_PORT 覆盖宿主端口
APP_PORT=9000 docker compose up -d web

# 一次性核查服务：Vitest 测试 + 生产构建 + 对 web 首页冒烟，结束即退出
docker compose build verify
docker compose run --rm verify
```

`verify` 挂在 `verify` profile 下且 `restart: "no"`，因此 `docker compose up`
**只**启动 web；核查永远是显式触发的一次性任务。它先等 web 健康检查通过，
再对 `http://web:8080` 做冒烟（HTML 挂载点、本地 JS/CSS 资源可达、无外部 CDN）。

## 数学说明

Artin 表示是忠实的（Artin 定理）：两个编带词相等当且仅当它们诱导相同的自由群自同构，
即初始终组 (x1,…,xn) 被映成逐分量相同的元组。因此“两路合法 + 自由群元组逐分量相等”
就是过程等价；元组不同则一定不等价，即使末端置换完全相同。
